# Ärmelabzeichen-Sammlung

Liste der Feuerwehr-Ärmelabzeichen mit Herkunft (Gemeinde, Landkreis, Regierungsbezirk bzw. Bundesland).

## So funktioniert's

1. Foto vom Abzeichen machen – gerade, gut beleuchtet, Wappen und Schrift gut sichtbar.
2. Foto an Claude schicken.
3. Antwort kommt: **schon vorhanden** oder **neu** – und woher das Abzeichen stammt.
4. Bei „neu“: „aufnehmen“ sagen, dann wird es in die Liste eingetragen.

## Inhalt

- `sammlung.csv` – die Liste (lässt sich mit Excel öffnen)
- `fotos/` – die Fotos der Abzeichen
- `CLAUDE.md` – Regeln für Claude
